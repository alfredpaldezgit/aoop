Project Overview

What is This Project?

This is a comprehensive, web-based Inventory Management System built with modern PHP, MySQL, and Bootstrap 5, following the Model-View-Controller (MVC) architectural pattern. The system provides complete CRUD (Create, Read, Update, Delete) functionality with advanced features including user authentication, detailed reporting, analytics, and real-time dashboard statistics.

Key Capabilities
  • Complete product inventory management
  • User authentication and role-based access control
  • Real-time dashboard with statistics and alerts
  • Multiple inventory report types with export functionality
  • Advanced analytics including ABC analysis
  • Secure data handling and validation

Setup & Installation

Prerequisites: You must have XAMPP installed with Apache and MySQL running

Step 1: Project Placement

Ensure the project folder (aoop) is located at: c:\xampp\htdocs\aoop\

Step 2: Start Services

  • Open XAMPP Control Panel
  • Click "Start" for Apache (should turn green)
  • Click "Start" for MySQL (should turn green)

Setup Methods

Method 1: Web Browser Setup (Recommended)
  1. Open your browser and navigate to: http://localhost/aoop/setup.php
  2. Click "Start Setup" button
  3. The wizard will create database, tables, and insert sample data
  4. After successful setup, click "Go to Application"
Default Credentials:
  • Username: admin
  • Password: admin123
Method 2: Command Line Setup (Windows)
  1. Open Command Prompt or PowerShell
  2. Navigate to the project directory: 
    cd C:\xampp\htdocs\aoop
  3. Run the setup batch file: 
    setup.bat
  4. Wait for the setup to complete
Method 3: Command Line Setup (Linux/Mac)
  1. Open Terminal
  2. Navigate to the project directory: 
    cd /path/to/aoop
  3. Make the script executable: 
    chmod +x setup.sh
  4. Run the setup script: 
    ./setup.sh
Method 4: Direct PHP CLI

Run directly from command line:

php setup-cli.php

Post-Setup Steps

  • Access the application at: http://localhost/aoop/
  • Login with admin credentials (admin / admin123)
  • IMPORTANT: Change the default admin password immediately
  • Create additional user accounts as needed
  • Configure application settings

Database Configuration

Edit config/database.php to change connection details:

define('DB_HOST', 'localhost');      // MySQL host
define('DB_USER', 'root');         // MySQL username
define('DB_PASS', '');             // MySQL password
define('DB_NAME', 'inventory_db'); // Database name

Security Features

  • Password Hashing: BCrypt hashing for secure password storage
  • SQL Injection Prevention: Prepared statements for all database queries
  • XSS Protection: Input validation and output escaping
  • CSRF Protection: Token-based protection against cross-site requests
  • Input Validation: Comprehensive validation for all user inputs
  • Rate Limiting: Protection against brute force attacks
  • Audit Logging: Track all system changes and user actions
  • Role-Based Access Control: Fine-grained permission management
Important Security Notes:
  • Always change the default admin password immediately after setup
  • Maintain regular database backups in production environments
  • Never commit database credentials to version control
  • Use HTTPS in production environments
  • Regularly update PHP and MySQL versions

Troubleshooting Guide

Database Connection Failed
  • Ensure MySQL is running in XAMPP
  • Check database credentials in config/database.php
  • Run setup.php again to reinitialize database
Login Always Fails
  • Check browser cookies/storage settings
  • Clear browser cache and cookies
  • Try creating a new user account
Images Not Uploading
  • Create public/uploads/images/ folder if it doesn't exist
  • Ensure folder permissions are writable (chmod 755)
  • Check PHP upload limits in php.ini
Port 3306 Already in Use
  • Another MySQL instance may be running
  • Change XAMPP MySQL port or stop conflicting service
  • Check for other MySQL installations running
