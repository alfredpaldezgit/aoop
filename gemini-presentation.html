OOP Concepts Applied

Chapter 8
Encapsulation

Models (e.g., `Product`) protect DB connection via `private` properties, exposing only public methods.

Single Responsibility

`SecurityHelper` handles validation only. `ReportGenerator` handles PDF creation only.

Data Abstraction

Usage of **PDO** abstracts database drivers, allowing switch between MySQL/PostgreSQL.

Key Algorithm: ABC Analysis
public function generateABCAnalysis() { // Sort products by total value (Price * Qty) $products = $this->getAllSortedByValue(); $totalVal = array_sum(array_column($products, 'val')); $cumulative = 0; foreach ($products as &$p) { $cumulative += $p['val']; $perc = ($cumulative / $totalVal) * 100; // Assign Class based on cumulative % $p['class'] = ($perc <= 80) ? 'A' : (($perc <= 95) ? 'B' : 'C'); } return $products; }
